# codex-status

一个基于 Electron、React 和 TypeScript 的 Codex 额度状态悬浮窗。

应用会在桌面显示一个胶囊窗口，按官方实际返回的额度窗口展示剩余或已用百分比，并提供系统托盘菜单、详情面板和设置面板。

## 友情社区

- [linux.do](https://linux.do/)

## 功能概览

- 悬浮胶囊窗口，常驻桌面顶层显示实际额度窗口，支持直接打开详情
- 支持剩余百分比 / 已使用百分比两种口径切换
- 官方 OAuth 可用时支持自动刷新和手动刷新
- 支持中英文界面
- 支持系统托盘菜单：显示/隐藏、刷新、设置、退出
- 读取官方额度接口，失败时仅展示同一账号最近 15 分钟内的官方历史结果，并标记状态

## 数据来源

应用按以下顺序读取额度信息：

1. 官方接口：`https://chatgpt.com/backend-api/wham/usage`
2. 同一账号的官方成功结果：仅保存在内存中，最长回退 15 分钟

会话 JSONL 无法可靠确认账号归属，因此不再用于额度回退。切换账号或退出登录会清空旧结果，同账号续期保留此前已确认的数据并重新同步；重置时间到达后等待官方确认，不自动推算为满额。

## 使用前提

- 若要读取官方额度，当前环境需要存在 `~/.codex/auth.json`
- `auth.json` 需要处于 ChatGPT OAuth 模式，并包含可用的 `access_token`
- 需要能够识别账号标识；面板显示脱敏账号、工作区和实际凭据路径（遵循 `CODEX_HOME`）
- 凭据不可用时显示连接原因；自动模式继续检查登录状态，手动模式可点击刷新重试

## 本地开发

### 网络连接

- 额度请求使用 Electron 网络栈，支持系统代理和 PAC。仅浏览器插件中的代理不一定对应用生效。
- 每次请求最多等待 20 秒（包括响应体读取）；临时网络故障或部分服务端错误等待 1 秒后最多重试一次，重试前重新核对登录账号和凭据。
- 登录失效、权限拒绝、限流及证书错误不立即重试；服务端要求延后重试时也不立即重发。失败原因可在详情的“连接信息”中查看。

```bash
npm install
```

### 启动开发环境

```bash
npm run dev
```

```bash
npm run typecheck
```

## 构建命令

```bash
npm run build
npm run build:unpack
npm run build:win
npm run build:mac
npm run build:linux
```

说明：

- `npm run build` 会先执行 TypeScript 检查，再执行 `electron-vite build`
- `npm run build:unpack` 会生成未打包目录
- 各平台打包命令会在当前平台配置基础上生成安装产物

## 使用方式

- 启动后会创建桌面胶囊窗口
- 点击系统托盘图标可显示或隐藏胶囊窗口
- 官方 OAuth 可用时，点击胶囊或托盘刷新项可立即手动刷新
- 从系统托盘菜单可打开设置面板、手动刷新或退出应用

## 状态持久化

应用会将窗口位置和设置保存到 Electron `userData` 目录下的 `codex-status-state.json`。
