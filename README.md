# codex-status

一个基于 Electron、React 和 TypeScript 的 Codex 额度状态悬浮窗。

应用会在桌面显示一个胶囊窗口，按官方实际返回的额度窗口展示剩余或已用百分比，并提供系统托盘菜单、详情面板和设置面板。

## 友情社区

- [linux.do](https://linux.do/)

## 功能概览

- 悬浮胶囊窗口，常驻桌面顶层显示实际额度窗口，支持直接打开详情
- 支持剩余百分比 / 已使用百分比两种口径切换
- 官方 OAuth 可用时支持自动刷新和手动刷新
- 支持中英文界面
- 支持系统托盘菜单：显示/隐藏、刷新、设置、退出
- 读取官方额度接口，失败时仅展示同一账号最近 15 分钟内的官方历史结果，并标记状态

## 数据来源

应用按以下顺序读取额度信息：

1. 官方接口：`https://chatgpt.com/backend-api/wham/usage`
2. 同一账号的官方成功结果：仅保存在内存中，最长回退 15 分钟

会话 JSONL 无法可靠确认账号归属，因此不再用于额度回退。切换账号或退出登录会清空旧结果，同账号续期保留此前已确认的数据并重新同步；重置时间到达后等待官方确认，不自动推算为满额。

## 使用前提

### 安装包选择

- Windows：`codex-status-<版本>-win-x86-x64-setup.exe`，同一个安装包包含 x86（32 位）和 x64（64 位），安装时自动选择。
- macOS：`codex-status-<版本>-mac-<架构>.dmg` 或 `.zip`；当前发布工作流构建 `arm64`，适用于 Apple Silicon。
- Linux：`codex-status-<版本>-linux-<架构>.AppImage` 或 `.deb`；当前发布工作流构建 `x64`。
- `.blockmap` 和 `latest*.yml` 是自动更新文件，无需手动下载。上述命名从下一次构建生效。
- Windows 安装后从桌面或开始菜单打开 `codex-status`；默认托盘模式，点击右下角数字图标打开详情，图标可能位于 `^` 折叠区。

### 账号连接

- 若要读取官方额度，当前环境需要存在 `~/.codex/auth.json`
- `auth.json` 需要处于 ChatGPT OAuth 模式，并包含可用的 `access_token`
- 需要能够识别账号标识；面板显示脱敏账号、工作区和实际凭据路径（遵循 `CODEX_HOME`）
- 凭据不可用时显示连接原因；自动模式继续检查登录状态，手动模式可点击刷新重试

## 本地开发

### 安装依赖

```bash
npm install
```

### 启动开发环境

```bash
npm run dev
```

### 代码检查

```bash
npm run lint
npm run typecheck
```

## 构建命令

```bash
npm run build
npm run build:unpack
npm run build:win
npm run build:mac
npm run build:linux
```

说明：

- `npm run build` 会先执行 TypeScript 检查，再执行 `electron-vite build`
- `npm run build:unpack` 会生成未打包目录
- 各平台打包命令会在当前平台配置基础上生成安装产物

## 使用方式

- 启动后会创建桌面胶囊窗口
- 点击系统托盘图标可显示或隐藏胶囊窗口
- 官方 OAuth 可用时，点击胶囊或托盘刷新项可立即手动刷新
- 从系统托盘菜单可打开设置面板、手动刷新或退出应用

## 用量估算

- 详情面板新增总额度、剩余额度（API 等价美元）、指定模型的输入 Token 折算、近期消耗速度和重置前耗尽提示。5h、7d 及其他实际返回的窗口分别估算，不能相加。
- 默认只展示本机新增 Token 统计和官方额度趋势。确认“当前仅此账号、此设备使用”后，才将之后的本机用量与官方百分比变化配对，计算 `预估总额度 = 采样等价费用 × 100 / 消耗百分点`。
- 总量至少需要 10 分钟、3 次有效观测和 5 个百分点消耗；无消耗、未知价格、日志缺失、缓存结果或重置时间未确认时不填猜测数值。范围只反映百分比取整误差，不是统计置信区间。
- 折算采用标准短上下文 API 单价（内置价格核对于 2026-09-15），不是实际账单或订阅计费权重，不含 Fast、长上下文、区域及工具加价。未知模型可在“本机模型用量与价格”中补充价格，补价会重新校准。
- 近期速度按最近一小时连续观测计算（包括空闲时间），预测取决于后续工作强度；其他设备、云端任务或无法观察的用量会影响总量准确性。
- 只解析 `CODEX_HOME/sessions` 中新增的模型和 Token 元数据，不保存聊天正文、不回填历史，也不将日志作为官方剩余百分比的兜底来源。
- 样本仅保存在本次运行内存中。重启、切账号或修改价格后重新采样；套餐或额度周期变化时丢弃旧周期样本。模型自定义价格随原设置保存。

## 状态持久化

应用会将窗口位置和设置保存到 Electron `userData` 目录下的 `codex-status-state.json`。
